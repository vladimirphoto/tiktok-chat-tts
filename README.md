# TikTok Chat TTS

Приложение для Windows, которое **читает вслух чат TikTok LIVE русским женским голосом**.
Подключается к эфиру по нику стримера, фильтрует спам и озвучивает сообщения по очереди.

* Голоса — бесплатные нейросетевые Microsoft Edge TTS (ключи и регистрация не нужны):
  **Светлана** (по умолчанию) — единственный родной русский женский голос в Edge TTS, плюс мультиязычные женские голоса (Ава, Эмма, Вивьен, Серафина), которые тоже читают по-русски.
* Чат — библиотека [TikTokLive](https://github.com/isaackogan/TikTokLive).
* Один файл `TikTokChatTTS.exe`, Python устанавливать не нужно.
* Тёмный интерфейс: статистика эфира (зрители, лайки, подарки, подписки), лента событий, обновление по кнопке.

## Как пользоваться

1. Скачайте `TikTokChatTTS.exe` из раздела **Releases** этого репозитория и запустите его.
2. Введите ник стримера (`@ник` или ссылку на эфир) и нажмите **Подключиться**. Стример должен быть в прямом эфире.
3. Выберите голос. Кнопка **Проверить голос** озвучит пример. Громкость регулируется в самой Windows.
4. Сообщения из чата попадают в журнал и озвучиваются по очереди.

Нужен интернет: голос синтезируется онлайн. Windows SmartScreen может предупредить о неизвестном издателе,
так как файл не подписан сертификатом: нажмите «Подробнее» → «Выполнить в любом случае».

### Что умеет

| Возможность | Описание |
|---|---|
| Фильтры | пропуск команд (`!`, `/`), ссылок, повторов и спама, чёрный список слов, только русские сообщения |
| Очистка текста | удаляет эмодзи и ссылки, схлопывает «приветтттт» в «привет», обрезает длинные сообщения |
| Очередь | следующая фраза синтезируется заранее; при переполнении старые сообщения отбрасываются |
| Управление | «Пропустить» текущую фразу, «Очистить очередь», ручной ввод текста |
| Подарки и подписки | можно озвучивать («Аня, спасибо за подарок Rose») |
| Устойчивость | сам переподключается, если эфир оборвался или стример ещё не начал трансляцию |
| Настройки | сохраняются в `%APPDATA%\TikTokChatTTS\settings.json` |

### Обновление программы

Каждая сборка в GitHub Actions публикуется в **Releases** с тегом `v1.0.<номер сборки>`. При запуске программа
в фоне проверяет последний релиз; если он новее, внизу окна появляется кнопка **«Обновить до X»**.
По нажатию новый `TikTokChatTTS.exe` скачивается, проверяется по контрольной сумме (`sha256.txt` из релиза),
программа закрывается и сама запускается уже в новой версии. Кнопка **«Проверить обновления»** делает проверку вручную.
Автообновление работает только из собранного exe в Windows и только если у папки с exe есть права на запись.

### Ограничения

* Подключение к TikTok неофициальное: библиотека использует сторонний сервис подписи Euler Stream.
  Бесплатный лимит подключений общий; при ошибке «лимит сервиса» подождите или укажите свой бесплатный
  ключ в поле «Ключ Euler Stream».
* Edge TTS — неофициальный бесплатный доступ к голосам Microsoft; Microsoft может изменить его без предупреждения.

## Разработка

```bash
pip install -r requirements.txt -r requirements-build.txt
python -m unittest discover -s tests -t .   # тесты
python run_app.py                           # запуск из исходников
python run_app.py --selftest --probe tiktok # живая проверка синтеза и подключения
python build_exe.py                         # сборка dist/TikTokChatTTS.exe (в Windows)
```

Сборка и проверка exe выполняются автоматически в GitHub Actions (`.github/workflows/build.yml`):
тесты, живой синтез голосов, сборка PyInstaller, самопроверка уже собранного exe и запуск окна.
Подробные отчёты каждой сборки лежат в ветке `ci-report`.

## Структура

```
ttchat/
  settings.py    настройки и их хранение
  textproc.py    очистка текста и фильтры
  tts.py         синтез речи (Edge TTS)
  updater.py     проверка релизов GitHub и обновление exe
  player.py      воспроизведение mp3 (Windows MCI)
  engine.py      очередь озвучки
  tiktok.py      подключение к чату и переподключение
  controller.py  связка «чат → фильтры → очередь»
  gui.py         окно (tkinter, тёмная тема)
  selftest.py    самопроверка для CI и exe
tests/           юнит-тесты
```
